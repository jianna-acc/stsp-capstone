# STS Capstone Project

STS Capstone Project is an AI-powered study management platform that helps students organize learning materials, create reviewers and quizzes, prioritize academic tasks, and generate personalized study plans.

The current project name is temporary and can be replaced later without changing the main system architecture.

## Current Development Phase

Phase 1 — Project Foundation

## Technology Stack

### Frontend

- Next.js with TypeScript
- Mantine UI
- CSS Modules
- Motion
- Tabler Icons
- Mantine Charts or Recharts

### Backend

- Python
- FastAPI

### Database and Authentication

- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage

### Artificial Intelligence

- Gemini API
- Google GenAI SDK
